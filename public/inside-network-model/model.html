Network architecture

The network has eight VLANs, 50 Windows 11 workstations, three administration scopes, and an internal time source. Splunk, Tenable/Nessus, and Trellix ePO/DLP each use one server instance.

The architecture is air-gapped. Boundary transfers use approved media under human control, and the root CA remains offline and non-domain-joined.
