Network Authorization / Course 2.1

Risk Management Framework.

Take the system you built in Build the Network through the first steps of the Risk Management Framework: define and register it, describe and categorize it in a draft System Security Plan, then select its controls with a draft risk assessment and a monitoring strategy. Each module follows one NIST step, with the matching JSIG tasks and the outputs they produce.
