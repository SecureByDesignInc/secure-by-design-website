1. Extract this entire folder from the ZIP.
2. Open index.html in a current Chrome, Edge, Firefox, or Safari browser.
3. Choose a chapter. The 3D network follows your place in the lesson.
4. Try Security reasoning and My evidence. Enter observations, check the

   record to resume in a different browser. You can also copy the record
   from its preview and paste it into Import record. Readable notes export
   as text.

WORKBOOK AND NOTICES
The 13-page workbook includes foundations (including where the controllers
live and the ports a domain member needs), configuration steps, domain
health checks, evidence questions, and Notices and permissions on page 13.
QR codes open the matching views in Inside the Network. DNS is taught in
course 1.2. The table of contents links directly to each section. The guide
footer links to notices.html, which includes the rights notice and software
license link.

The lesson code and 3D assets are bundled without external dependencies. The workbook links
need the files to stay beside index.html. Source links and links to the
website need an internet connection. Some mobile file viewers restrict local HTML;
open it in a full browser or use the published guide on securebydesigninc.com.

The lesson uses sample names and addresses (sbd.test, 10.0.10.10 and
10.0.10.11 on VLAN 10, gateway 10.0.10.1) and steps based on Microsoft
documentation. It has not been tested on your Windows Server environment,
so check each result yourself. The recorded walkthrough is coming soon; the
video panel says so until then. Progress in this downloaded copy stays in
your browser. Nothing is uploaded.

The scene illustrates chapter states. It does not connect to your VMs, run
commands, or validate your server configuration. Completion records your
learning activity. Keep credentials out of notes and evidence exports.
