SECURE BY DESIGN - PROMOTE PRIMARY & SECONDARY DOMAIN CONTROLLER
Course 1.1 | Materials edition 0.7 | Updated 14 October 2026
Sample: sbd.test; SBD-DC01 10.0.10.10 and SBD-DC02 10.0.10.11 on VLAN 10, gateway 10.0.10.1
Read-only checks. Run them on the controllers (later, from the Tier 0 administration host)
with the Windows Server tools and access they need. Review every result; nothing in this
file runs by itself.

Give every system a purpose
hostname
Get-NetIPConfiguration
w32tm /query /status

Expected observations: The two names and static addresses match your plan, the default gateway is 10.0.10.1, and SBD-DC02 lists 10.0.10.10 as its DNS server. Record actual time-source output; a configured address alone does not prove time synchronization.

Create the first domain controller
Get-ADDomain | Select-Object DNSRoot, NetBIOSName
Get-Service NTDS,Netlogon
Get-SmbShare -Name SYSVOL,NETLOGON

Expected observations: The domain is sbd.test with NetBIOS name SBD. NTDS and Netlogon are running, and SYSVOL and NETLOGON shares exist. Investigate missing services or shares before moving on.

Give the domain a second service point
Get-ADDomainController -Filter * |
  Select-Object HostName, IPv4Address, IsGlobalCatalog
repadmin /replsummary
repadmin /showrepl SBD-DC02

Expected observations: Both hostnames appear with the intended addresses and global catalog roles. After initial convergence, replication checks show successful recent attempts and no unresolved replication failures. Inspect errors rather than assuming the restart completed replication.

Ask the domain to prove it works
dcdiag /s:SBD-DC01
dcdiag /s:SBD-DC02
repadmin /replsummary
repadmin /showrepl *
Get-ADDomainController -Filter * | Select-Object HostName, IsGlobalCatalog
netdom query fsmo
Get-SmbShare -Name SYSVOL,NETLOGON -CimSession SBD-DC02
Get-NetConnectionProfile | Select-Object InterfaceAlias, NetworkCategory
Get-NetFirewallProfile -PolicyStore ActiveStore |
  Select-Object Name, Enabled, DefaultInboundAction

Expected observations: Each controller passes its DCDiag tests, or every failure has a recorded cause. Replication shows recent successful attempts in both directions and no failures. Both controllers are global catalogs, SBD-DC01 holds the five operations master roles, SYSVOL and NETLOGON are shared on both, and each controller reports the DomainAuthenticated profile with every firewall profile on and inbound blocked by default. Save output with host, time, and interpretation; a command that ran is not a pass.

Leave a build someone else can understand
Get-ADDomain |
  Select-Object DNSRoot, PDCEmulator, RIDMaster, InfrastructureMaster
Get-ADForest |
  Select-Object RootDomain, SchemaMaster, DomainNamingMaster

Expected observations: The record identifies the actual role holders and links configuration decisions to dated test results. Open issues remain visible. Lesson completion records learning activity; it is not a system authorization decision.
