SECURE BY DESIGN - DC01 AND DC02
Sample: sbd.test, 10.0.10.10 and 10.0.10.11
Read-only checks. Run in your environment with the necessary Windows server tools and access.
Review results; no checks are automatically run by this package.

Give every system a purpose
hostname
Get-NetIPConfiguration
Get-DnsClientServerAddress -AddressFamily IPv4
w32tm /query /status

Expected observations: The two names and static addresses match your plan. DC02 points to 10.0.10.10 for DNS. Record actual time-source output; a configured address alone does not prove time synchronization.

Create the first domain controller
Get-ADDomain | Select-Object DNSRoot, NetBIOSName
Get-Service NTDS,DNS,Netlogon
Get-SmbShare -Name SYSVOL,NETLOGON

Expected observations: The domain is sbd.test with NetBIOS name SBD. NTDS, DNS, and Netlogon are running, and SYSVOL and NETLOGON shares exist. Investigate missing services or shares before moving on.

Give the domain a second service point
Get-ADDomainController -Filter * |
  Select-Object HostName, IPv4Address, IsGlobalCatalog
repadmin /replsummary
repadmin /showrepl SBD-DC02

Expected observations: Both hostnames appear with the intended addresses and global catalog roles. After initial convergence, replication checks show successful recent attempts and no unresolved replication failures. Inspect errors rather than assuming the restart completed replication.

Ask the services to prove they work
$servers = '10.0.10.10','10.0.10.11'
foreach ($server in $servers) {
  Write-Output "DNS server: $server"
  Resolve-DnsName '_ldap._tcp.dc._msdcs.sbd.test' -Type SRV -Server $server
  Resolve-DnsName 'SBD-DC01.sbd.test' -Type A -Server $server
  Resolve-DnsName 'SBD-DC02.sbd.test' -Type A -Server $server
}
dcdiag /test:DNS /e /v
repadmin /replsummary

Expected observations: Each DNS service returns domain locator records for the configured controllers and the correct host addresses. Review DCDiag findings and replication failures individually. Save output with host, time, and interpretation; do not record an automatic pass because the command ran.

Leave a build someone else can understand
Get-ADDomain |

Get-ADForest |

Expected observations: The record identifies the actual role holders and links configuration decisions to dated test results. Open issues remain visible. Lesson completion records learning activity; it is not a system authorization decision.
