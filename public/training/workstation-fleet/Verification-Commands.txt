SECURE BY DESIGN - BRING IN THE FLEET
Course 1.7 | Materials edition 1.4 | Updated 9 October 2026

Run each check in an elevated PowerShell session, or a shell on the Linux servers, on the host the lesson names.
Some lessons include the configuration commands they verify: read each command before you run it, and adapt
the example names, addresses, and paths to your own plan. Nothing in this file runs by itself.

1. Prepare the fleet rollout
Get-FileHash -Algorithm SHA256 C:\Staging\Win11-Reference.vhdx
Get-ADOrganizationalUnit -Identity 'OU=Workstations,OU=SBD,DC=sbd,DC=test'
Get-GPInheritance -Target 'OU=Workstations,OU=SBD,DC=sbd,DC=test'
Get-GPOReport -Name 'SBD Workstation Firewall' -ReportType Html -Path C:\Evidence\workstation-fleet\workstation-firewall.html

What success looks like: The image is hashed and recorded, the join account holds only the delegated right on the Workstations OU, and the STIG and firewall GPO links show on that OU before any machine exists in it.

2. Join the pilot and inspect first boot
Get-ADComputer -SearchBase 'OU=Workstations,OU=SBD,DC=sbd,DC=test' -Filter * | Select-Object Name, DNSHostName
gpresult /r /scope:computer
Resolve-DnsName SBD-PC01.sbd.test
Test-NetConnection SBD-PC02.sbd.test -Port 445   # expected: TcpTestSucceeded False

What success looks like: All three pilots sit in the Workstations OU with STIG policy applied and DNS registered, peer SMB/RDP fails as designed, and the join events are visible in analysis.

3. Manage local administrators with Windows LAPS
Get-LapsADPassword -Identity SBD-PC01 -AsPlainText   # from SBD-ADMIN-PC01, Tier 2 admin
Get-ADComputer SBD-PC01 -Properties msLAPS-PasswordExpirationTime | Select-Object Name, msLAPS-PasswordExpirationTime
gpresult /r /scope:computer

What success looks like: The schema holds the LAPS attributes, only the Tier 2 group can read passwords, the policy shows on the pilots, and one retrieve-use-rotate cycle is recorded.

4. Autoenroll the fleet's certificates
gpupdate /force
Get-ChildItem Cert:\LocalMachine\My | Select-Object Subject, NotAfter
certutil -verify -urlfetch C:\Evidence\fleet\SBD-PC01.cer

What success looks like: Pilot endpoints enroll hands-free at policy refresh, verification passes with live publication retrieval, and the CA's issued log reflects the fleet with the widened template version.

5. Admit only enrolled devices with 802.1X
# On an enrolled pilot: the wired interface authenticated with EAP-TLS.
netsh lan show interfaces
# On SBD-DHCP01: recent NPS grants (6272) and denials (6273).
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=6272,6273} -MaxEvents 5 | Select-Object TimeCreated, Id

What success looks like: Every pilot authenticates with EAP-TLS and NPS logs the grant (6272); a failed authentication is logged but, in monitor mode, the port still forwards on VLAN 80; the ports name VLAN 90 as their failure VLAN; and the NPS events appear in the collector.

6. Scale to fifty, enforce 802.1X, and prove by sample
(Get-ADComputer -SearchBase 'OU=Workstations,OU=SBD,DC=sbd,DC=test' -Filter *).Count
# On SBD-DHCP01: authentication results in the last hour (6272 granted, 6273 denied).
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=6272,6273; StartTime=(Get-Date).AddHours(-1)} | Group-Object Id | Select-Object Name, Count
Get-DhcpServerv4ScopeStatistics -ScopeId 10.0.80.0 | Select-Object PercentageInUse, AddressesInUse
Get-WinEvent -LogName ForwardedEvents -MaxEvents 5 | Select-Object MachineName, Id

What success looks like: Fifty computer objects sit in the Workstations OU, every PC enrolled and authenticates, the ports enforce 802.1X with the unenrolled laptop quarantined in VLAN 90, scope utilization matches the rollout, every sampled host passes the full check set, and fleet events flow through the pipeline.

7. Delta scan the fleet and hand off
Get-ChildItem C:\Evidence\workstation-fleet -Recurse | Select-Object Name, LastWriteTime
Get-FileHash -Algorithm SHA256 C:\Evidence\workstation-fleet\*

What success looks like: Sampled endpoints hold dated Windows client baselines, the infrastructure rescans carry attributed deltas, and the fleet inventory is complete and filed.
