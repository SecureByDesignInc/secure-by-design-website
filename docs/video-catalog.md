# Training Hub and companion materials

The Training Hub at `/technical-training` (`app/videos/training-hub.tsx`, owner direction 19 October 2026) shows the whole catalog (`content/videos.json`) as one library: a sidebar of the catalog's categories with the Build the Network topic groups (`collections`) under them, a featured course, and rows of tiles. A library tile opens the shared expanded tile (`app/videos/episode-tile.tsx`) beneath its row. The ATO Package Builder Hub at `/grc-rmf-training` is the practice tool and has no tiles. Each expanded tile contains its complete build explorer, recording, and companion training materials. The first package, course 1.1 (Promote Primary & Secondary Domain Controller), covers DC01 and DC02 on Windows Server. Its recording is still in preparation; the workbook and guide are available. The user authorized publication of the catalog changes on October 4, 2026.

## Content

`content/videos.json` retains `platforms` for the shared social links and defines `episodes` for the catalog. Each episode contains its title, subtitle, description, tags, display number, system labels, chapters, and training asset paths. It also provides `outcomeSummary` and `outcomes` for the learning objectives, plus optional `scene` and `networkLabel` fields. Keep episode IDs unique, chapter IDs nonempty and unique within each episode, and workbook page counts positive integers. Add only real, prepared entries; do not fill the catalog with invented future episodes.

The supported `scene` value is `identity-dc`, which uses the DC01/DC02 topology and requires exactly five ordered chapter IDs: `prepare`, `dc01`, `dc02`, `verify`, and `evidence`. Both the tile's 3D label and scene mounting use this validated mapping. A different topology or chapter-to-scene mapping needs its own scene implementation. An omitted or unsupported scene value, or an incompatible chapter sequence, displays the written chapter explorer without mounting this identity model. Its video and training materials remain available.

Leave `youtubeId` null until the recording is published. Then add the verified 11-character YouTube ID, and set chapter timestamps to verified nonnegative offsets in seconds. The page embeds the video using YouTube's privacy-enhanced iframe and chapter start parameters. No autoplay is requested. Unknown or invalid IDs display the coming-soon panel. No fake durations or timestamps are shown. Embedded-video reference: https://developers.google.com/youtube/player_parameters

Training assets live in `public/training/dc01-dc02/`: the interactive HTML guide, the PDF and Word workbooks, verification commands, lesson data, license, and complete ZIP. Each tile offers one download, that ZIP (configuration courses have their own `SecureByDesign-<id>-Learning-Package.zip`). The cover image is rendered from the real workbook. Replace the files together when revising an episode, then run `python3 scripts/prepare-training-packages.py` to regenerate the download packages and the 1.1 manifest. The workbook omits the reading recommendations and closing note removed by the user.

## Interactions

Collapsed tiles use five desktop columns, then four, three, two, and one as the viewport narrows. Every tile's artwork shows its workbook cover in the same place and size as the first episode's; course tiles set their three labels to its left. Their artwork is 124px tall, mobile tile width is capped at 240px, and the opening control remains at least 44px tall. The latest desktop check measured a tile at approximately 222 by 335px, 21% narrower and 23% shorter than the preceding revision. Tags and the full description remain in the expanded view.

`training-hub.tsx` owns the library, search, the groups' View all pages and the open tile; `video-utils.ts` holds the group, artwork and recently-updated helpers. Search is case-insensitive and matches every whitespace-separated query token across title, subtitle, description, tags, and system names. Topic choices are sorted unique tags from the real catalog; the selected topic uses an exact tag match. Search and topic filters combine. The first 12 matching episodes are shown in editorial order, and Show more episodes adds another 12. A result count and clear-filter empty state help readers recover from searches with no matches.

Explore episode opens the complete experience inside that tile. Only one tile can be expanded at a time. Opening another tile or closing the current one unmounts the previous experience, including its scene, video iframe, and chapter timer. Search, topic changes, and filter resets also close the expanded episode and reset the visible count to 12. Clear filters returns focus to search; the bottom Close episode control returns focus to its tile's opener. Reopening an episode starts a fresh explorer session.

`episode-experience.tsx` owns the active episode's chapter and motion state. The chapter buttons select the build state. In the identity scene, selecting a server, the health-check console, or the evidence record selects the corresponding chapter. Drag rotates, scroll zooms, arrow keys rotate the focused scene, and Home or Reset view restores the camera. The verify chapter follows a health check to either controller. Play the build story advances the chapters until paused or manually selected. Ambient motion can be paused independently; reduced-motion preferences start it paused. The scene releases graphics resources on unmount and pauses rendering when out of view. If graphics fail, the chapter navigation and written explanation remain usable.

An explicit chapter selection or system selection sets the video's chapter start offset when a verified timestamp is available. Automatic build-story playback changes only the chapter and 3D view; it does not seek or reload the embedded video.

The chapter controls also provide a keyboard-accessible equivalent to 3D selection. At mobile widths the inspector follows the stage, and video and training materials stack vertically. The companion guide maintains its existing browser-local progress; this catalog does not add account synchronization.
